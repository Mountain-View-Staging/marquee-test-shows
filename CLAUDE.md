# Marquee test shows — PUBLIC

Everything in this repository is public. Read README.md's rules before adding anything: generic
content only, generated media and openly licensed fonts only, no real show codes, no live
service URLs, no internal identifiers. CI runs a leak scan on every push, and the Pages deploy
runs it again before it publishes.

The shows are generated by a tool outside this repository and committed; never hand-edit a
show. Everything under `shows/` and the `.db` files in `legacy/` are generated; the README, the
scripts, the workflows and `legacy/README.md` / `legacy/expected.json` are written by hand.

- To reset: `scripts/reset.sh`. To check a checkout: `python3 scripts/leak-scan.py`,
  `scripts/verify.sh`, `scripts/budget.sh`, and `scripts/load-cartridges.mjs` with a checkout of
  the Cartridge Specification.
- A test copies a show before opening it; `scripts/lock.sh` makes the authoring databases
  read-only so nothing opens one here in place.
- The leak scan's patterns live in `scripts/leak-scan.py` alone (the scan skips that file). Real
  codes, event names and brand names are listed there as SHA-256 digests, never as text, and a finding is
  reported by position, never by its text: CI logs are public too.
